# Security policy

Please report vulnerabilities in Worked or this repo by email to **security@worked.dev**.
You can also use GitHub's private 'Report a vulnerability' button on this repository's Security tab.

Do not open public GitHub issues, pull requests or discussions for security problems. We will acknowledge your report and keep you updated while we fix it.

We acknowledge reports within 3 business days, give a first assessment within 7 days, and coordinate disclosure within 90 days.
